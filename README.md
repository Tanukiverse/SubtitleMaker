# Subtitle Maker

โปรแกรม Windows ทำซับวิดีโออัตโนมัติในเครื่อง: ถอดเสียง → แปลเป็นไทย → ไฟล์ `.srt`
ทำงานทีละขั้นและแก้ได้ทุกขั้น (แนวเดียวกับ MangaTranslator)

1. **ดึงเสียง**: ffmpeg → wav 16 kHz
2. **ถอดเสียง**: faster-whisper (ตรวจภาษาเอง ญี่ปุ่น/อังกฤษ/อื่นๆ) ปล่อย VRAM ทันทีหลังเสร็จ
3. **จัดบรรทัด**: ตัดคำหลอนของ Whisper (ซ้ำ, "ขอบคุณที่ติดตาม"), รวมประโยคสั้นที่ติดกัน
4. **แปล**: Ollama ทีละชุด 25 บรรทัด พร้อมบรรทัดก่อนหน้าเป็นบริบท และอภิธานศัพท์
5. **ส่งออก**: ตัดบรรทัดไทยด้วย pythainlp (ไม่ตัดกลางคำ), ปรับเวลาให้พออ่านทัน, เขียน `<ชื่อวิดีโอ>.th.srt`

## ติดตั้ง
ต้องมี Python 3.12, ffmpeg (อยู่ใน PATH) และ Ollama
```
setup.bat
```
ดึงโมเดลแปลที่จะใช้ เช่น `ollama pull hf.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive:Q4_K_M`
โมเดล Whisper ดาวน์โหลดเองครั้งแรกที่ใช้ลง `models\whisper` (`large-v3-turbo` ราว 1.6 GB)

## ใช้งาน
ดับเบิลคลิก `Start SubtitleMaker.bat` แล้วลากวิดีโอ/เสียง (หลายไฟล์ได้) มาวาง กด **▶ ทำทั้งหมด** (F5) หรือกดทีละขั้น
- แก้คำแปลในตารางได้ (ดับเบิลคลิก) แถวที่แก้เองถูก 🔒 ล็อก ขั้นอัตโนมัติจะไม่เขียนทับ
- คลิกแถวเพื่อข้ามไปจุดนั้นในเครื่องเล่น ซับตัวอย่างแสดงใต้วิดีโอ
- **💾 บันทึก .srt** (Ctrl+S) เขียนไฟล์ใหม่หลังแก้ ไฟล์อยู่ข้างวิดีโอ หรือโฟลเดอร์ที่ตั้งไว้ใน ⚙ ตั้งค่า
- ⚙ ตั้งค่า: โมเดล Whisper (tiny…large-v3), ภาษาในเสียง, โมเดล Ollama, อภิธานศัพท์, ความยาวบรรทัด, โฟลเดอร์ส่งออก

## เพิ่มเติม (รอบ UI แบบ Subtitle Edit)
- **ธีมมืด**, แถวตารางสลับสี, ขนาดฟอนต์ตาราง/กล่องแก้ไข, ขนาด/ตำแหน่ง/สีซับบนวิดีโอ ตั้งใน ⚙ ตั้งค่า
- **เปิดไฟล์ .srt** (Ctrl+Shift+O หรือลากมาวาง): ใช้เป็นคำแปลหรือต้นฉบับ แทนรายการซับปัจจุบัน ย้อนกลับได้
- **🔄 แปลใหม่ที่เลือก**: เลือกหลายแถวในตาราง (หรือคลิกขวา) แปลซ้ำเฉพาะแถวนั้น โดยใช้บรรทัดก่อนหน้าเป็นบริบท
- **🔎 หาชื่อตัวละคร/ศัพท์เฉพาะ** (แท็บ อัตโนมัติ): โมเดลสแกนซับทั้งเรื่อง แล้วเปิดหน้าต่างให้ตรวจ/แก้คำแปลก่อนเพิ่มเข้าอภิธานศัพท์ (โมเดลเดาชื่อผิดได้ จึงต้องตรวจเสมอ)
- **เลือกโมเดลแปล** ในแท็บ อัตโนมัติ
- **ไฟล์ → ส่งออก**: MP4 ฝังซับลงภาพ (ฟอนต์ไทยตั้งใน ⚙, ค่าเริ่มต้น Leelawadee UI), MKV/MP4 ใส่ซับเป็นแทร็ก (ไม่ถ่ายภาพซ้ำ) ไม่เขียนทับวิดีโอต้นฉบับ

## CLI
```
.venv\Scripts\python -m subtitle_maker.cli video.mp4 --from auto --to th
.venv\Scripts\python -m subtitle_maker.cli video.mp4 --steps audio,asr,tidy,export   # ไม่แปล: ได้ .srt ต้นฉบับ
```
